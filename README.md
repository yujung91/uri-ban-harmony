# 우리 반 하모니 · 그림과 4마디 작곡

집 PC에서 이어서 작업하려면 [HOME_SETUP.md](HOME_SETUP.md)를 먼저 읽으세요. 개발 구조와 운영 연결 정보는 [HANDOFF.md](HANDOFF.md)에 정리했습니다.

2026-11-03 업데이트: 숫자 8자리 참여 코드, 명시적 교사 입장과 연결 계정 표시, 학생 화면 미리보기, 교사·학생용 매뉴얼, 상황 그림 약속 카드, 스펙트럼 색상 선택, 가사·4마디 멜로디·그림 창작, 학생 원본을 보존하는 교사 수정, 마디 기반 음악 영상 구성을 추가했습니다. 새 음성 제출과 녹음 기능은 제거했습니다.

예시 그림은 미리 생성해 `public/assets/rule-atlas.png`에 포함했습니다. 학생 사용 중 AI API 호출은 없으며, 멜로디 네 곡은 코드로 구성한 예시입니다.

## 새 창작·영상 흐름

1. 약속 제안은 상황 그림 6개 중 선택하거나 직접 쓰기·그리기로 참여합니다.
2. 함께 만들기는 가사·멜로디·그림을 중심으로 구성됩니다. 각 작품을 승인된 약속과 연결할 수 있습니다.
3. 멜로디는 4/4박자·다장조·4마디로, 예시 4개·음표 길이·쉼표·빠르기·음별 가사를 편집합니다. 빈 박자는 쉼으로 연주합니다.
4. 교사는 모든 제출물을 작성자·약속·활동·검토 상태로 필터링합니다. 교사 수정은 첫 학생 원본과 각 수정 전 상태를 보관하며 원본 확인·복원이 가능합니다. 작품 투표는 없습니다.
5. 승인된 멜로디·가사·리듬을 영상의 곡·자막·리듬으로 선택하고, 그림·영상을 장면에 넣습니다. ‘음악·가사·장면 설정’에서 순서·1~8마디 길이·별도 자막을 조정합니다.
6. 제목·마침 화면은 각각 1마디이며, 곡은 장면 길이에 맞춰 반복합니다. 재생과 WebM 녹화에 같은 Web Audio/Canvas 시계를 사용합니다. 자동 가창은 제공하지 않습니다.
7. 기존 학급의 영문 코드는 교사가 새 입장 화면에서 학급을 선택할 때 숫자 코드로 전환됩니다. 기존 학생의 참여 토큰과 제출물은 유지됩니다.

이하의 초기 버전 설명 중 음성 참여와 고정 5초 장면에 관한 내용은 위 업데이트로 대체됩니다.

학생은 참여 코드로 들어오고 교사는 자신의 ChatGPT 계정으로 관리합니다. 자료는 Cloudflare D1과 R2에 학급별로 보관되며, 다른 기기에서 함께 참여할 수 있습니다. 화면은 3초마다 새 활동을 조회합니다.

## 수업 진행

1. 선생님 로그인 → 새 학급 만들기 → 학급 이름·학생 수·기간·참여 방식 설정.
2. 학생에게 사이트 주소와 8자리 코드를 안내합니다. 학생은 코드로 입장해 자동 별명을 받습니다.
3. 약속 모으기에서 문장·그림·음성으로 제안합니다. 교사가 승인하면 다른 학생에게 표시됩니다.
4. 교사가 투표를 열고 학생들이 투표합니다. 교사가 최종 약속을 선정하고 창작을 시작합니다.
5. 학생들이 작품을 제출하면 교사가 검토 후 영상에 넣습니다.
6. 뮤직비디오를 재생·다운로드합니다. 설정에서 참여를 닫거나 학급 자료를 백업·삭제할 수 있습니다.

학생은 ChatGPT 계정·이메일·실명 없이 참여합니다. 학생이 입장하려면 Sites의 접속 범위가 공개여야 합니다. 공개되는 것은 입장 화면이며, 학급 내용은 참여 코드로 발급받은 개인 토큰 또는 해당 교사의 로그인 권한이 있어야 열립니다. 코드는 학급 안에서만 안내하세요.

## 구현

- Sites Vinext 서버, D1 데이터베이스, R2 미디어 저장소
- 플랫폼 로그인 헤더로 교사 신원 검증, 프로젝트 소유자 검사
- 학생별 256비트 무작위 참여 토큰; DB에는 SHA-256 해시만 저장
- 자동 별명, 약속 제안·승인·숨김·검토 요청, 중복 방지 투표
- 가사·멜로디·그림·리듬·사진·영상 작품 제출 및 검토
- 승인된 장면 구성·순서 변경, 구성 버전 보관·복원
- 소리 포함 WebM 다운로드, 미디어 포함 학급 JSON 내보내기
- 참여 닫기·다시 열기, 코드 재발급, 학급 데이터와 파일 삭제
- 서버 측 입력·권한·참여 단계 검사와 요청 횟수·업로드 용량 제한

## 운영 범위

- 학생 파일 10MB/개, 참여자당 업로드 40개·100MB, 제안/작품 각 20개까지입니다.
- 새 기기나 시크릿 창으로 입장하면 새 참여자로 집계됩니다. 같은 기기·브라우저를 계속 사용하세요.
- 참여 코드는 일반적인 학급 활동용 접근 수단입니다. 코드를 아는 사람은 참여할 수 있으므로 실명·민감정보를 올리지 않고, 얼굴·목소리는 필요한 동의를 확인한 자료만 사용하세요.
- 활동 마감일 이후 학생의 새 제안·작품 제출이 차단됩니다. 전체 참여 닫기는 투표와 업로드도 차단합니다. 기존 학생 토큰은 코드 변경 후에도 유지됩니다.
- 미디어는 자동 만료되지 않습니다. 교사가 설정의 ‘학급 삭제’로 데이터와 R2 파일을 삭제할 수 있습니다. 내보낸 백업은 별도로 관리하세요.
- 기존 브라우저 로컬 MVP 자료는 자동 이전하지 않습니다. 서버 학급은 빈 상태로 시작합니다.
- 버전 복원은 약속·장면 선택과 프로젝트 설정을 복원합니다. 숨김 상태의 작품은 자동 공개하지 않습니다.
- 학급 백업은 내보내기 전용입니다. 서버에 가져오는 복원 기능은 제공하지 않습니다.
- Chrome/Edge를 권장합니다. 영상은 마디 길이에 맞춘 WebM이며, 녹화 중 해당 화면을 유지하세요. 녹화 중 정지하거나 다른 화면으로 이동하면 불완전한 파일을 내려받지 않습니다.

## 개발·검증

```sh
npm run install:ci
npm run db:generate
npm run build
# 아래 로컬 마이그레이션은 새 로컬 DB에 한 번만 적용
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_even_ben_grimm.sql
npm run dev -- --port 4173 --hostname 127.0.0.1
```

배포 환경의 `TEACHER_EMAIL`은 Sites의 비밀 환경변수로 관리합니다. 소스나 프런트엔드에 교사 정보를 넣지 않습니다. 로컬 로그인 검증은 `.dev.vars`에 `TEACHER_EMAIL="seedy@sites.test"`를 설정하고 개발 서버를 재시작합니다. `.dev.vars`는 Git에 포함되지 않습니다.

```sh
node scripts/test-classroom.mjs

```
